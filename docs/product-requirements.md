# Windows Monitor 产品需求文档

版本：v0.1  
日期：2026-06-11  
状态：草案

## 1. 产品定位

Windows Monitor 是一款 Windows 桌面监控软件，用于持续识别桌面和窗口内容，对窗口标题、OCR 文本、指定软件任务栏闪烁状态进行监听，并在命中关键词或触发状态变化时发送消息提醒。

适用场景：

- 客服、交易、运维等需要同时盯多个窗口的工作台。
- 需要监听弹窗、系统提示、软件通知、业务关键词的桌面环境。
- 需要在离线或弱联网环境中部署，并通过机器唯一编码完成授权的软件。

## 2. 用户与角色

| 角色 | 目标 | 权限 |
| --- | --- | --- |
| 普通用户 | 开启监听、查看提醒、调整个人规则 | 查看授权状态、管理本人监听规则、查看日志 |
| 管理员 | 配置授权、更新、全局通知方式 | 管理全部规则、通知渠道、更新策略、导入导出配置 |
| 授权管理员 | 生成离线授权文件或在线授权 | 查看机器码、绑定设备、吊销授权 |

MVP 可先不做账号体系，默认本机管理员即拥有全部权限。

## 3. 产品目标

### 3.1 MVP 目标

1. 支持监听所有可见窗口标题，只要命中关键词即发送消息提醒。
2. 支持对桌面和窗口截图进行 OCR 识别，命中关键词即发送消息提醒。
3. 支持为某个任务栏软件配置闪烁监听，检测到闪烁时发送提醒。
4. 支持规则管理：关键词、匹配方式、监听范围、通知频率、启停状态。
5. 支持本机唯一编码授权，并支持离线授权成功。
6. 支持在线检查更新、下载更新、安装更新。

### 3.2 非目标

- 不做远程控制、屏幕录制回放、键盘鼠标行为监控。
- 不读取用户输入内容，不做密码框 OCR，不采集浏览器隐私数据。
- 不保证能识别被系统保护、硬件加速或 DRM 保护的窗口内容。

## 4. 核心流程

### 4.1 首次启动

1. 用户启动软件。
2. 软件读取机器唯一编码并展示授权页。
3. 用户选择在线授权或导入离线授权文件。
4. 授权成功后进入主控台。
5. 软件引导用户创建第一条监听规则。

### 4.2 创建关键词监听

1. 用户进入“监听规则”。
2. 点击新增规则。
3. 选择监听对象：全部窗口、桌面、指定窗口、指定进程。
4. 输入关键词，可设置多个关键词。
5. 选择匹配方式：包含、正则、大小写敏感、全词匹配。
6. 选择监听内容：窗口标题、OCR 内容、两者都监听。
7. 设置提醒方式与冷却时间。
8. 保存并启用规则。

### 4.3 触发提醒

1. 后台监听服务周期性采集窗口标题和截图 OCR。
2. 命中规则后生成事件。
3. 去重和冷却策略判断是否发送。
4. 发送系统通知、声音提醒、企业微信/钉钉/Webhook 等消息。
5. 事件写入本地日志。

### 4.4 任务栏闪烁监听

1. 用户进入“任务栏闪烁”。
2. 选择目标软件或进程，例如 QQ、微信、企业 IM、业务系统。
3. 启用闪烁监听。
4. 当任务栏按钮出现闪烁或高亮提醒状态时，软件发送通知。
5. 同一进程在冷却时间内重复闪烁只记录一次提醒。

## 5. 功能需求

### 5.1 主控台

展示内容：

- 当前监听状态：运行中、暂停、异常。
- 今日事件数、关键词命中数、OCR 成功率、平均 OCR 耗时。
- 正在监听的窗口数、进程数。
- 最近 20 条提醒事件。
- 授权状态和版本状态。

操作：

- 一键开始/暂停监听。
- 手动触发一次 OCR 扫描。
- 打开规则、日志、授权、更新页面。

验收标准：

- 用户可以在 3 秒内确认软件是否正常监听。
- 监听异常时展示明确原因，例如 OCR 引擎不可用、截图权限不足、授权过期。

### 5.2 窗口标题监听

功能：

- 监听所有可见顶层窗口标题。
- 支持包含、正则匹配。
- 支持按进程名、窗口类名、标题关键词过滤。
- 支持黑名单：密码管理器、浏览器隐私窗口、用户自定义排除列表。

验收标准：

- 新打开窗口标题命中关键词时，10 秒内发送提醒。
- 窗口标题变化后可以被下一轮扫描识别。

### 5.3 OCR 内容监听

识别语言：

- 中英文混合识别。
- 用户可在设置中查看当前 OCR 引擎支持的语言包状态。

监听范围：

- 全桌面 OCR。
- 全部窗口逐个 OCR。
- 指定窗口 OCR。
- 指定屏幕区域 OCR。

规则能力：

- 多关键词：任一命中、全部命中。
- 正则表达式。
- 匹配冷却时间。
- OCR 置信度阈值。
- 同一文本去重。

验收标准：

- 用户可查看每次 OCR 的原始识别文本。
- 命中提醒应包含窗口标题、进程名、命中关键词、识别文本片段、截图时间。
- OCR 失败时记录错误，不阻断标题监听。

### 5.4 任务栏闪烁监听

功能：

- 支持选择目标软件：从当前运行的软件、进程、窗口列表中选择。
- 支持按进程名持久化配置，例如 `WeChat.exe`。
- 识别任务栏按钮闪烁或提醒状态。
- 支持同一目标冷却提醒。

验收标准：

- 目标软件任务栏闪烁时发送消息提醒。
- 目标软件关闭后状态显示为“未运行”，重新启动后自动恢复监听。
- 用户可在运行软件列表中选择目标，不需要提前内置固定软件名单。

待技术验证：

- Windows 对“读取其他软件任务栏闪烁状态”没有统一稳定的直接查询 API，MVP 需要通过 WinEvent Hook、UI Automation 或任务栏可访问性状态做兼容验证。

### 5.5 提醒通知

MVP 通知渠道：

- Windows 系统通知。
- Webhook。

规则支持同时勾选多个通知渠道。默认启用 Windows 系统通知，Webhook 由用户配置地址后启用。

后续可扩展：

- 企业微信机器人。
- 钉钉机器人。
- 飞书机器人。
- 邮件。
- 短信。

通知内容：

- 规则名称。
- 命中类型：标题、OCR、任务栏闪烁。
- 命中关键词。
- 窗口标题和进程名。
- 发生时间。
- 文本摘要。

去重策略：

- 默认同一规则、同一窗口、同一关键词 60 秒内只提醒一次。
- 用户可按规则调整冷却时间。

### 5.6 授权

授权方式：

- 在线授权：输入授权码，联网校验并绑定机器码。
- 离线授权：展示机器唯一编码，导入授权文件完成本机授权。

授权周期：

- 按天授权。
- 按月授权。
- 按年授权。
- 永久授权。

授权状态：

- 未授权。
- 已授权。
- 授权即将过期。
- 已过期。
- 授权文件无效。
- 设备不匹配。

机器唯一编码要求：

- 同一台电脑重装软件后保持一致。
- 尽量避免单一硬件变更导致失效。
- 不采集敏感个人信息。

验收标准：

- 断网情况下可通过导入离线授权文件完成授权。
- 授权文件被复制到其他电脑后不可用。
- 授权过期后停止后台监听，但允许进入授权页。

### 5.7 在线更新

功能：

- 手动检查更新。
- 启动时按策略静默检查更新。
- 展示更新版本、大小、发布时间、更新说明。
- 支持下载、校验签名、安装。
- 支持失败回滚到旧版本。
- 更新包托管在 GitHub Releases。

策略：

- 默认不强制更新。
- 可配置强制更新最低版本。
- 支持跳过某个版本。
- 默认使用 stable release，不安装 prerelease，除非用户切换到测试通道。

验收标准：

- 更新包签名校验失败时禁止安装。
- 更新失败不影响当前版本继续运行。

### 5.8 日志与审计

日志类型：

- 监听事件日志。
- 通知发送日志。
- OCR 错误日志。
- 授权日志。
- 更新日志。

保留策略：

- 默认保留 30 天。
- 支持导出 CSV。
- 支持按规则、窗口、关键词、时间筛选。

## 9. 隐私与安全

- 本地默认只保存命中事件，不保存完整屏幕截图。
- 用户可选择开启命中截图留存。
- 密码框、浏览器隐私窗口、用户排除进程默认不 OCR。
- Webhook 通知只发送摘要，完整 OCR 文本默认不出站。
- 授权文件和本地配置需要加密存储。

## 10. 版本规划

### v0.1 MVP

- 主控台、规则管理、标题监听、中英混合 OCR 监听、Windows 通知、Webhook、托盘运行、日志、离线授权、GitHub Releases 手动更新。

### v0.2

- Webhook、企业微信/钉钉/飞书、任务栏闪烁兼容增强、规则导入导出、指定区域 OCR。

### v0.3

- 多屏幕高级配置、远程授权管理、增量更新、日志报表。

## 11. 已确认范围

1. 通知渠道支持多选，MVP 默认提供 Windows 通知和 Webhook。
2. OCR 识别语言为中英文混合。
3. 授权周期支持按天、按月、按年、永久。
4. 在线更新包使用 GitHub Releases 托管。
5. 任务栏闪烁监听目标从当前运行的软件列表中选择。

## 12. 待确认问题

1. 目标系统最低版本：Windows 10、Windows 11，还是需要支持 Windows Server？
2. Webhook 消息格式是否需要兼容你已有接口，还是先使用产品默认 JSON 格式？
3. GitHub Releases 仓库是公开还是私有？私有仓库需要配置访问 token。
4. 是否需要授权生成工具或授权管理后台？
